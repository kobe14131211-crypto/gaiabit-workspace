# GaiaBit PM | Animal Data Network 2026

全功能離線/線上支援之專案管理與行事曆系統。

## 特色功能
1. **側邊欄與頁籤選單**：完全對照截圖選單（今日總覽、雙週 Roadmap、任務中心、行事曆、E・臨時事項、Animal ESG、Animal Data...）。
2. **首次登入設定管理者帳密**：首次啟動會提示設定管理者帳號與密碼，設定後僅管理者登入可新增、編輯、刪除工作與事件；其他訪客僅能瀏覽。
3. **行事曆整合 (FullCalendar)**：所有新增的工作與行程會同步自動連動顯示在月曆上。
4. **即時切換與持久化儲存**：全瀏覽器端 JavaScript，隨拆即用。
